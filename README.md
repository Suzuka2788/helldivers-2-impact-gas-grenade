# Suzuka's impact gas grenade v1.6.1

Changes the G-16 impact grenade to release the G-4 gas payload on contact. Version 1.6.1 includes the G-4 particle, material, texture, stream, and GPU resources needed to display the gas cloud. The user confirmed the visual fix in game with the v1.6.1 preview.

## Install

1. Install Bingus Shared Loader v15 or newer (API 1).
2. Disable previous G-16 Gas Impact versions.
3. Download `Suzukas-Impact-Gas-Grenade-v1.6.1.zip` from the latest Release, import it into your mod manager, deploy, and restart the game.

Log: `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\SuzukaImpactGasGrenade.log`. The mod verifies the target record before writing and restores its change on shutdown when safe. Future game updates require renewed validation.
